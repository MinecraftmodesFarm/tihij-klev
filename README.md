# Тихий клёв — онлайн-версия

Игра (Three.js) + сервер Node.js (Express + Socket.IO). Игроки видят друг друга в реальном времени:
позиции, заброс, поплавок, леску, процесс вываживания, общий чат и список онлайн (клавиша **Q**).

```
server.js        сервер (npm start, порт из PORT)
package.json
render.yaml      готовая настройка для Render (необязательно)
public/
  index.html     игра
  game.js        код игры и сетевой клиент
  config.js      адрес сервера (по умолчанию пусто = тот же адрес, откуда открыта игра)
```

## 1. Загрузить на GitHub
1. На github.com: **New repository** → имя, например `tihij-klev` → **Create repository** (README и .gitignore не добавляй).
2. Распакуй архив. В репозитории нажми **uploading an existing file**, перетащи **всё содержимое папки** (`server.js`, `package.json`, `render.yaml`, `.gitignore`, `README.md` и папку `public` целиком) → **Commit changes**.
   Или командами:
   ```
   git init && git add . && git commit -m "Тихий клёв онлайн"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/tihij-klev.git
   git push -u origin main
   ```
   В корне репозитория должен лежать `package.json`.

## 2. Запустить на Render
1. render.com → **New +** → **Web Service** → подключи GitHub и выбери репозиторий.
2. Поля:
   - **Runtime / Language:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** `Free`
   - **Health Check Path** (в Advanced): `/health`
   - Переменные окружения (необязательно): `ALLOWED_ORIGINS` — `*` (по умолчанию) или список адресов через запятую, например `https://ТВОЙ_ЛОГИН.github.io`. `PORT` Render задаёт сам.
3. **Create Web Service**. Через 1–3 минуты открой адрес вида `https://tihij-klev.onrender.com` — это и есть игра. Проверка сервера: `https://tihij-klev.onrender.com/health` покажет `{"ok":true,"online":0,...}`.
4. Дай друзьям ту же ссылку. В меню выбери режим **Мультиплеер**, нажми «Начать рыбалку». В шапке будет «Онлайн: N», по **Q** — список игроков со странами, по **Enter** — чат.

Вместо шагов 2–3 можно в Render выбрать **New + → Blueprint** — настройки возьмутся из `render.yaml`.

## Если игра лежит отдельно (GitHub Pages и т.п.)
Открой `public/config.js` и впиши: `window.TK_SERVER_URL = "https://tihij-klev.onrender.com";`. Либо добавь к ссылке `?server=https://tihij-klev.onrender.com`. В `ALLOWED_ORIGINS` на Render укажи адрес страницы с игрой (или оставь `*`).

## Как это работает
- Клиент шлёт ~10 раз в секунду своё состояние: позиция, поворот, этап рыбалки (замах, заброс, ожидание, поклёвка, вываживание), координаты и «поклёвку» поплавка. Сервер проверяет и ограничивает значения и рассылает остальным игрокам.
- Чат: ограничение 1 сообщение в 0,7 с, длина до 160 символов, последние 30 сообщений видит каждый вошедший.
- Потеря связи: клиент сам переподключается каждые 0,7–5 с и заново входит, в чате пишет «Соединение потеряно / восстановлено».
- Ботов в онлайн-версии нет: в списке только живые игроки.

## Игровой контент (этап 6)
- В каталоге 100 видов рыб: для каждого заданы вес, размерная модель, редкость, наживка, место обитания, глубина, время активности и характер сопротивления.
- В игре 10 локаций с отдельным процедурным рельефом, водоёмом, окружением и набором рыб.
- Дневник показывает параметры видов, а карточки локаций — доступных рыб.
- Рыбы создаются процедурно: объёмное тело с чешуйчатой текстурой, плавники с лучами, жаберные линии и глаза; хвост анимируется при движении. Деревья и модели рыбаков также собраны из процедурной геометрии, без сторонних игровых ассетов.
- Глубина и время активности влияют на поведение рыб.
- Все 10 индексов локаций принимаются сервером для сетевой синхронизации.
- Покупка локаций и серверные сохранения ещё не реализованы; добавленные локации пока доступны сразу.

## Удочки и вываживание
- Инвентарь снастей открывается клавишей **I** или кнопкой с названием установленной удочки в HUD.
- В инвентаре можно купить и установить одну из четырёх удочек; приобретённый выбор сохраняется в локальном профиле. Установку можно быстро переключать клавишами **F1–F4**.
- У каждой удочки свои дальность заброса, прочность и скорость подмотки. Старые сохранения автоматически продолжают работу с начальной удочкой, не теряя прежний баланс и улучшения лески/заброса.
- Фрикцион регулируется в инвентаре снастей. Во время рывков ослабленный фрикцион отдаёт леску, а слишком высокое натяжение может привести к обрыву.
- При поклёвке нажми кнопку заброса/действия, чтобы начать вываживание; удерживай для подмотки и отпускай во время сильных рывков.

## Ограничения
- Бесплатный план Render «засыпает» после ~15 минут без заходов; первое открытие после сна занимает до минуты.
- Рыба, деньги и дневник считаются на устройстве каждого игрока. Сервер не проверяет честность уловов, он только пересылает данные.
- Регистрация и вход (CATx и другие) сохраняются в браузере, это не защита: админ-команды работают только у самого игрока и других не касаются.
- Локально проверены запуск, меню, аккаунт, дневник, магазин, сохранение настроек и мультиплеер через два Socket.IO-клиента. Игру в браузере на настоящем Render не проверял.
