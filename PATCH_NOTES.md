# Патч: серверная экономика + анти-чит

## Что изменилось

1. **Деньги/улов/удочки/апгрейды теперь считает сервер**, а не браузер игрока —
   для всех, кто вошёл в аккаунт и играет онлайн. Гости (без аккаунта) и офлайн-режим
   работают как раньше, локально.
2. **Анти-чит с предупреждением.** Если сервер видит подделанное действие
   (несуществующая рыба, невозможный вес, слишком частые поклёвки, покупка без денег
   и т.п.) — игрок видит красный оверлей "Замечено необычное действие, связанное с
   читерством" с кнопкой "Я понимаю и больше так не буду делать" (разблокируется через
   10 сек, сам оверлей держится ещё 10 сек после клика/разблокировки).
3. **3 нарушения подряд = аккаунт удаляется**, все данные (деньги, улов, снасти)
   стираются безвозвратно. Игрока отключает от сервера с оверлеем об этом.
4. **Команда `/admin 546777`** в чате — выдаёт права администратора аккаунту **CATx**
   (и только ему; привязано к имени аккаунта на сервере, не к коду одному). Код задаётся
   на сервере в переменной окружения `ADMIN_BOOTSTRAP_KEY` (сейчас это `546777`, смени
   на проде на что-то длиннее).

## Важно при деплое на Render

Задай переменные окружения:
- `AUTH_SECRET` — любая длинная случайная строка (иначе токены слетают при рестарте).
- `ADMIN_NAMES` — опционально, запасной список ников-админов через запятую.
- `ADMIN_BOOTSTRAP_KEY` — код для выдачи админки через `/admin <код>` (по умолчанию 546777).

## Известное ограничение

Админ-команды `/money`, `/give`, `/trophy` остались как локальная "песочница" для
админа (не защищены от перезаписи сервером при следующей продаже/покупке) — это
осознанный компромисс, чтобы не делать весь патч неподъёмным по времени. Если нужно —
могу перевести и их на сервер отдельным заходом.
